## Repository layout

```text
myapps/
├── apps/           # Individual applications (one folder per app)
├── .github/        # Issue/PR templates and GitHub Actions
├── CONTRIBUTING.md # How to add or update projects
├── LICENSE
└── README.md
```

## Getting started

1. **Clone the repository**

   ```bash
   git clone https://github.com/imusved1/myapps.git
   cd myapps
   ```

2. **Open a specific app** (once you add one)

   ```bash
   cd apps/<app-name>
   # Follow the README in that directory
   ```

3. **Add a new app** — see [CONTRIBUTING.md](CONTRIBUTING.md).
