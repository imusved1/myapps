# Contributing

Thank you for your interest in contributing to **myapps**.

## Adding a new app

1. Create `apps/<app-name>/` with a clear, descriptive name (lowercase, hyphens).
2. Include a `README.md` in that folder with setup and usage instructions.
3. Add a `.gitignore` inside the app folder if it has language-specific artifacts not covered by the root `.gitignore`.
4. Update the **Projects** table in the [root README](README.md).

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Keep changes focused on one app or one documentation update.
3. Ensure CI passes before requesting review.
4. Fill out the pull request template completely.

## Issues

Use the issue templates for bugs and feature requests. Include steps to reproduce, expected behavior, and environment details when relevant.

## Code style

- Match the conventions of the app you are editing.
- Prefer clear names and small, focused changes over large refactors.
