# Apps

Each subdirectory here is a self-contained application.

## Adding an app

1. Create a folder: `apps/<app-name>/`
2. Add a `README.md` with:
   - What the app does
   - Prerequisites and install steps
   - How to run and test
3. Keep app-specific config inside that folder (e.g. `package.json`, `requirements.txt`).
4. Update the project table in the [root README](../README.md).

## Naming

- Use lowercase with hyphens: `my-cool-app`
- Avoid spaces and special characters in folder names
